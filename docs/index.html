# Module 4 · Lists in Python

# Create a list of items
fruits = ["apple", "banana", "cherry"]

# Access elements by index (0-based)
print(fruits[0]) # → "apple"
print(fruits[-1]) # → "cherry"

# List methods
fruits.append("mango")
fruits.remove("banana")

# Iterate over a list
for fruit in fruits:
    print(f"I like {fruit}")

# List comprehension (Pythonic!)
upper = [f.upper() for f in fruits]

// Polish Checklist

Portfolio-ready means the project is easy to inspect.

  • README with problem, features, setup, and what changed from the base idea.
  • Three screenshots or a short demo video that proves the project runs.
  • GitHub commits, comments, tests, and a reflection on tradeoffs or bugs.
  • One deployment link or reproducible local setup for reviewers.

Admissions-minded FAQ

What counts as meaningful? A project with a real user, personal question, original dataset, or clear improvement over time.

Solo or team? Both work, as long as the student can name their own decisions, tradeoffs, and contributions.
